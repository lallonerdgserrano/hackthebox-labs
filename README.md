# Hack The Box Labs

Laboratorios prácticos de **ciberseguridad, pentesting básico, enumeración de servicios y explotación de vulnerabilidades**.

Este repositorio forma parte de mi portafolio técnico y está orientado a documentar la resolución de máquinas de la plataforma Hack The Box, demostrando la aplicación de metodologías de seguridad, análisis de red y remediación de configuraciones inseguras.

## Objetivo del repositorio

Demostrar habilidades prácticas en ciberseguridad mediante laboratorios documentados con:

*   Información del objetivo (OS, Dificultad, Enfoque)
*   Reconocimiento y escaneo de red (Reconnaissance)
*   Enumeración de servicios e identificación de vulnerabilidades
*   Procedimiento de explotación (Exploitation)
*   Extracción de banderas (Flags)
*   Lecciones aprendidas y comandos clave

## Áreas cubiertas

*   Escaneo y descubrimiento de redes
*   Enumeración de protocolos (FTP, SMB, etc.)
*   Explotación de configuraciones por defecto y accesos anónimos
*   Uso de herramientas de línea de comandos en entornos Linux
*   Documentación técnica de hallazgos de seguridad

## Estructura de cada laboratorio

Cada máquina está documentada con una estructura orientada a reportes técnicos profesionales:

1. **Overview:** Datos generales de la máquina y el enfoque técnico.
2. **Reconnaissance & Enumeration:** Evidencia del escaneo de puertos, versiones y servicios activos.
3. **Exploitation:** Paso a paso detallado de la explotación de la vulnerabilidad encontrada.
4. **Key Takeaways & Commands Learned:** Conclusión técnica y resumen de herramientas aplicadas.

## Herramientas utilizadas

Algunas de las herramientas y recursos utilizados en estos laboratorios incluyen:

*   **Sistemas Operativos:** Kali Linux
*   **Reconocimiento:** Nmap
*   **Análisis de red:** Wireshark
*   **Conectividad:** Clientes FTP
*   **Documentación:** Markdown

## Propósito profesional

Este repositorio busca mostrar evidencia verificable de aprendizaje aplicado, pensamiento analítico y capacidad para documentar procesos de auditoría de seguridad de forma clara y estructurada. Cada laboratorio refleja mi metodología para abordar vulnerabilidades, detallar los vectores de ataque y documentar el impacto técnico.
